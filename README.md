# Puncto website

Static website for Puncto, ready for GitHub Pages. No build step is required.

## Publish with GitHub Pages

1. Create a GitHub repository and push this folder to its default branch.
2. In the repository, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, choose the default branch, and select the **/(root)** folder.
4. Save. GitHub will publish the site at the URL shown in the Pages settings.

Update `sitemap.xml` with the final GitHub Pages or custom-domain URL after publishing.
